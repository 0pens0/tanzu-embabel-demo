# Embabel Demo Quick Reference
## Presenter's Cheat Sheet

### 🚀 Quick Start Commands
```bash
# Start the demo
mvn spring-boot:run

# Open browser
open http://localhost:8080
```

### 🎯 Key Talking Points

#### 1. **Opening Hook (30 seconds)**
> "What if you could build AI agents using the same Java skills you already have? No new languages, no configuration files, just clean, testable, enterprise-ready code."

#### 2. **Core Value Proposition (1 minute)**
- **Java-First:** Full type safety, IDE support, refactoring
- **Spring Integration:** Dependency injection, AOP, enterprise features  
- **AI-Powered:** Sophisticated planning beyond finite state machines
- **Testable:** Unit tests, integration tests, familiar tools

#### 3. **Building Blocks (2 minutes)**
- `@Agent` - Just a Spring bean with an annotation
- `@Action` - Regular Java methods that can be chained
- `@AchievesGoal` - Represents the final objective
- **Domain Models** - Java records for type safety
- **Personas** - Different AI personalities for different tasks
- **LLM Mixing** - Right model for each task

### 🛠️ Troubleshooting

#### **If Demo Fails:**
- Show the static code examples
- Focus on the architecture and annotations
- Emphasize the Java-first approach

#### **If Questions Arise:**
- **"How does this compare to LangChain?"** - "LangChain is Python-based and configuration-driven. Embabel is Java-based with full type safety and Spring integration."
- **"Is this production ready?"** - "Yes, this is built by the Spring Framework team with enterprise needs in mind. It includes monitoring, health checks, and all the features you expect from Spring Boot."
- **"Can I integrate with existing Spring apps?"** - "Absolutely. Agents are just Spring beans. You can inject them anywhere and use all Spring features."
