What is Embabel?

Embabel is a sophisticated AI agent framework created by the team behind Spring Framework. It enables developers to build intelligent applications that combine the power of Large Language Models with traditional programming paradigms.

Key Differentiators

  • ✓ Sophisticated Planning: Goes beyond finite state machines with true AI-powered planning
  • ✓ Strong Typing: Full object-oriented programming with Java/Kotlin type safety
  • ✓ Built-in Testability: Comprehensive unit and integration testing support
  • ✓ Spring Integration: Seamless integration with the Spring ecosystem

From the Creator of Spring

Embabel is developed by the same team that created the Spring Framework, bringing decades of experience in enterprise Java development to the world of AI agents.

Building Blocks

Embabel models agentic flows using these core concepts. Each building block is designed to work seamlessly with Java's type system and Spring's dependency injection.

@Agent

Agent

Defines a class as an Embabel agent. All agents are Spring beans and can be injected with dependencies. 

@Agent(description = "Break down tasks into steps")
public class TaskBreakdownAgent {
    // Agent implementation
}
@Action

Action

Methods that represent steps an agent can take. Actions can be chained and executed in sequence. 

@Action
Task analyzeTask(UserInput input, 
                 OperationContext context) {
    // Action implementation
}
@AchievesGoal

Goal

Methods that represent goal achievement. These are called when the agent completes its objective. 

@AchievesGoal(description = "Plan created")
@Action
ExecutionPlan createPlan(Task task, 
                        List<Step> steps) {
    // Goal achievement
}
Records

Domain Model

Strongly-typed objects that inform the agent's behavior. Uses Java records for immutable data structures. 

public record Task(
    String description,
    String category,
    String complexity
) {}
Persona

Personas

Different LLM personalities for different tasks. Optimizes AI behavior for specific use cases. 

static final Persona ANALYST = 
    new Persona("Project Analyst", 
                "Expert in task breakdown");
LLM

LLM Mixing

Using different models and temperatures for different tasks. Cost-effective and optimized AI usage. 

.withLlm(LlmOptions
    .withAutoLlm()
    .withTemperature(0.3))

Why Choose Embabel?

Embabel provides unique advantages that set it apart from other agent frameworks.

Sophisticated Planning

Goes beyond finite state machines with true AI-powered planning. Agents can dynamically replan based on execution results, enabling them to handle tasks they weren't explicitly programmed for.

Strong Typing & OOP

Full object-oriented programming with Java/Kotlin type safety. No more magic maps or string-based configurations. Enjoy full IDE support, refactoring, and compile-time error checking.

Built-in Testability

Comprehensive testing support with FakeOperationContext for unit tests and full integration testing capabilities. Test your agents just like any other Spring component.

Spring Integration

Seamless integration with the Spring ecosystem. Agents are Spring beans, can use dependency injection, AOP, and all Spring features. Leverage existing enterprise infrastructure.

Platform Abstraction

Clean separation between programming model and platform concepts. Run locally during development, deploy to cloud platforms like Cloud Foundry with higher QoS without changing application code.

LLM Mixing

Use different models and temperatures for different tasks. Optimize for cost and capability by using the right AI model for each specific task in your agent workflow.
